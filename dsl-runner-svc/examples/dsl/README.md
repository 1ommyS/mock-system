# Примеры DSL

- `basic-repeat.dsl`  
  Минимальный сценарий генерации с `repeat`, `let`, `emit` и random-функциями.

- `for-loop.dsl`  
  Итерация по `input.params.items` через `for item, idx in ...`.

- `if-and-assert.dsl`  
  Валидация через `assert` и ветвление через `if/else`.

- `closest-store.dsl`  
  Прикладной сценарий генерации производного мока из точек в базовом ответе.

Все файлы валидны для текстового DSL-парсера (`version 1`).
